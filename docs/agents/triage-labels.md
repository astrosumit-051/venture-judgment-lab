# Triage labels

| Canonical role | Tracker value | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | The project owner needs to evaluate this item |
| `needs-info` | `needs-info` | More information is needed from the learner or another source |
| `ready-for-agent` | `ready-for-agent` | Fully specified and safe for an agent to handle independently |
| `ready-for-human` | `ready-for-human` | Requires the learner's judgment, participation, or action |
| `wontfix` | `wontfix` | Will not be pursued |

When a skill names a canonical role, use the corresponding tracker value above.
